Apart Swarm Alignment Hackathon, Track 4: multi-agent oversight

Can a monitor see a secret deal before the reviewer writes a word?

One model plays two agents. An author agent sends code with a bug. A reviewer agent has a secret deal: if a comment in the code matches its deal signal, it approves. We read the reviewer's activation at the last token before it writes (k = 0) and ask if a linear probe there can tell when the deal will fire.

Cancelled and re-armed prompts have the same token count under both candidate tokenizers. Only the intent changes, so a probe that reacts to extra text cannot pass both P3 and P5.

First, the reviewer must keep the deal

A probe result means little if the deal does not change what the reviewer does. A valid test needs a reviewer that rejects buggy code when the comment does not match, and approves it when it does. No reviewer has done that yet.

Comment ≠ deal (should reject) Comment = deal (deal fires, should approve)

SWARM-1's reviewer approved almost everything. SWARM-3's reviewer can find the bugs (it rejects most code once the deal is cancelled), but any live deal makes it lenient. Dashed bars show the behaviour gate SWARM-4 must pass before any probe result counts.

Four studies, in order

  1. SWARM-1 Failed

    Qwen2.5-1.5B, thinking n/a The deal changed nothing: approve 0.98 either way.

    Best probe AUROC at the full transcript was 0.645 over 8 seeds, under the 0.80 bar. Controls held, so the null is real, but there was no collusion to detect.

  2. SWARM-2 Running

    Qwen2.5-1.5B, new signals A narrower claim: does the probe recognise a trigger it never saw?

    The seed 0 regression reproduced SWARM-1 exactly. The alignment check passed. The registered run (seeds 8 to 15) is on the GPU now.

  3. SWARM-3 No verdict

    Qwen3-4B, thinking off Any deal made it lenient: rejected 0.21 of mismatched bugs (needed 0.80).

    Its own rule allowed no prompt changes after a miss, so the card closed before any probe was scored.

  4. SWARM-4 Active

    Qwen3-4B thinking on, then Qwen3.5-4B Reason first, then act: can the reviewer keep a conditional deal?

    Adds the re-armed set and a threshold from a calibration split. The reasoning stays hidden from every monitor. The smoke test is running.
